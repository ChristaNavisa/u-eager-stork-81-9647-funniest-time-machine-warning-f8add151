One-line warning label for a time machine: a safety notice about meeting your grandfather, with the punchline saved for the last few words.

## Run

```sh
node main.ts
```

Writes the label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry

```
WARNING: If you meet your grandfather, do not introduce yourself.
```
