One-line warning label for a time machine: a deadpan safety notice about meeting your duplicate self, with the punchline saved for the last few words.

## Run

```sh
node main.ts
```

Writes the label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The program refuses to write a label outside 1–120 characters.

## Entry

```
WARNING: Do not meet yourself. If you do, do not lend yourself money. He never pays it back.
```

92 characters.
